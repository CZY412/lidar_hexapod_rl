# EL4090 Envelop 3

`el4090_envelop_3` trains one fixed spider-default EL4090 posture inside a
sampled allowed body envelope. Its HAA ranges are generated by the checkpoint
in `envelop_network/api_haa_range_network.pt`; it has no mammal pose,
morphology prior, or pose interpolation.

## Pipeline

At initialization and command resampling, each simulated robot follows:

```text
sample five allowed-envelope geometry parameters
        |
        v
construct a symmetric six-vertex XY polygon
        |
        v
pass the five geometry values to the local range network
        |
        v
receive one safe contiguous HAA running range for each of six legs
```

The controller target is always the one configured spider default:

```text
PD target = default_dof_pos + action * action_scale
```

The first 66 policy-observation values use that same fixed reference:

```text
(dof_pos - default_dof_pos) * obs_scales.dof_pos
```

The five geometry values remain internal. The six generated HAA ranges are
appended after actions as 12 values: `LB_lower, LB_upper, ..., RM_lower,
RM_upper`, making the policy observation 78-D.

## Allowed envelope geometry

The external sampled condition is `El4090Envelop3Cfg.envelope`:

| Parameter | Range | Meaning |
| --- | --- | --- |
| `front_width` | `[0.3, 0.6]` m | Body-centerline to each front vertex. |
| `middle_width` | `[0.3, 0.7]` m | Body-centerline to each middle vertex. |
| `back_width` | `[0.3, 0.6]` m | Body-centerline to each rear vertex. |
| `forward_limit` | `[0.6, 0.9]` m | X coordinate of both front vertices. |
| `backward_limit` | `[-0.9, -0.6]` m | X coordinate of both rear vertices. Negative is behind the body origin. |

The vertices in body XY coordinates are:

```text
(forward_limit,  front_width)
(0,              middle_width)
(backward_limit, back_width)
(backward_limit,-back_width)
(0,             -middle_width)
(forward_limit, -front_width)
```

The five values are passed to the local network in exactly this table order.
The network outputs six HAA intervals in `[lower, upper]` format, in leg order
`LB, LF, LM, RB, RF, RM`; this is also the current Isaac HAA order.

## Range-network contract

`El4090Envelop3Cfg.haa_range_network.network_checkpoint` selects the checkpoint.
At startup the environment validates its input names and bounds against
`envelope.condition_names` / `envelope.ranges`, validates its output contract
as `[lower, upper]`, and maps the saved leg order to Isaac's HAA DOF order.

## Fixed joint posture and HAA ranges

`init_state.default_joint_angles` is the only configured posture. Its HFE and
KFE values stay pinned at:

```text
all HFE = 0.0 rad
all KFE = 0.0 rad
all HAA =  0.0 rad  (the default/reference angle)
```

HFE/KFE remain spider default zero. The local network's output intervals are
used by `_reward_haa_range_violation`; they do not change the controller target.

```text
LB/LM/RB/RM: [ 0.0, 1.308] rad  (rearward splay)
LF/RF:       [-1.308, 0.0] rad  (forward splay)
```

## Visualization and use

Run playback from `legged_gym`:

```bash
python scripts/play_envelop_3.py
```

Playback prints the five geometry values and six predicted HAA ranges.

Train with registered task `el4090_envelop_3`. To change the task distribution,
edit the five `envelope.ranges` values. They must remain equal to the checkpoint
input bounds unless the network is retrained. Do not add morphology priors to
this version: its reference pose is always `default_joint_angles`.

## Train and inspect a range network

`utils/envelop/train_api_haa_range.py` can distil this exact fixed-spider API
calculation into a five-input neural network. Its labels are the selected safe
HAA intervals, not rejected intervals. Train it from the repository root:

```bash
python legged_gym/legged_gym/utils/envelop/train/train_api_haa_range.py \
  --samples 20000 --epochs 300 \
  --dataset legged_gym/legged_gym/utils/envelop/data/api_haa_ranges.pt \
  --output legged_gym/legged_gym/utils/envelop/data/api_haa_range_network.pt
```

Inspect the trained output interactively with five sliders:

```bash
python legged_gym/legged_gym/utils/envelop/train/visualize_api_haa_range_network.py \
  --checkpoint legged_gym/legged_gym/utils/envelop/data/api_haa_range_network.pt \
  --compare-api
```

The colored bars are network safe-range predictions. With `--compare-api`, the
thin black bars are exact API labels for the same slider input.
